# 32-bit ARM support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** omnishell installs and applies on armv6l/armv7l Linux, and `mise` and `starship` use upstream release binaries there.

**Architecture:** Release assets gain an optional `goarm` key. `platform.Info` carries the host's GOARM variant (read from the running binary's build info) and `Fallback.AssetFor` takes it as a third argument, preferring an exact variant match and then a variant-less asset. GoReleaser publishes `linux/arm` archives for GOARM 6 and 7, and `install.sh` maps `armv6l`/`armv7l`/`armv8l` to them.

**Tech Stack:** Go 1.26, GoReleaser v2, POSIX sh, TOML manifests.

**Spec:** `docs/superpowers/specs/2026-10-06-arm32-support-design.md`

## Global Constraints

- Release archives: `omnishell_linux_armv6.tar.gz` and `omnishell_linux_armv7.tar.gz`; existing archive names are unchanged.
- `install.sh` mapping: `armv6l` -> `armv6`; `armv7l`, `armv8l` -> `armv7`; any other `arm*` -> "unsupported arch".
- Asset key `goarm` is `"6"` or `"7"` and is only valid together with `arch = "arm"`.
- `AssetFor(os, arch, goarm)`: exact `goarm` match first, then an asset with no `goarm`. An asset with a `goarm` never matches a different or empty host variant.
- broot keeps its git fallback on 32-bit ARM (no upstream asset). Only `mise` and `starship` gain assets.
- `ComputePlan` stays side-effect-free; all shelling out stays behind `Runner`.
- English everywhere in code, comments, docs and commits. Commit format `<type>: <description>`, no attribution trailers.
- Every behaviour change carries a test. Run the minimum relevant tests while iterating and `make test vet lint` before handing off.

## Review Focus

- A host running a plain `go build` binary (empty GOARM): matches only variant-less assets, so mise falls through to the git build instead of installing an armv7 binary on a possibly-armv6 CPU. Tested in Task 2.
- `GOARM` build-setting values with a float suffix (`"7,softfloat"`, `"6,hardfloat"`): the variant is the leading digit. Tested in Task 1.
- amd64/arm64 hosts: their `goarm` is empty and they must keep matching the existing variant-less assets. Tested in Task 2.
- A manifest with `goarm` on a non-arm arch, or `goarm = "5"`: rejected at load, so a typo cannot silently never match. Tested in Task 2.
- `uname -m` of `armv8l` (32-bit userland on a 64-bit CPU) installs the armv7 archive; `armv5tel` and `armv7` are refused with the existing error. Tested in Task 4.

```go
// Info is the full host description omnishell needs.
type Info struct {
	OS   OS
	Arch string
	// GoARM is the 32-bit ARM variant ("6" or "7") the running binary was built
	// for. It is empty off 32-bit ARM and when the build did not record one.
	GoARM     string
	HomeDir   string
	ConfigDir string
	Shells    []ShellInfo
}

// Env holds the runtime/environment dependencies of detection, injectable for tests.
type Env struct {
	GOOS   string
	GOARCH string
	// GoARM is the raw GOARM build setting of the running binary (for example
	// "7" or "7,softfloat"); see GoARMFromBuild.
	GoARM    string
	Getenv   func(string) string
	LookPath func(string) (string, error)
}

// GoARMFromBuild returns the GOARM setting the running binary was built with,
// or "" when the build info does not record one.
func GoARMFromBuild() string {
	bi, ok := debug.ReadBuildInfo()
	if !ok {
		return ""
	}
	for _, s := range bi.Settings {
		if s.Key == "GOARM" {
			return s.Value
		}
	}
	return ""
}

// goARMVariant normalizes a raw GOARM setting to "6" or "7": the leading digit,
// ignoring a float-ABI suffix such as ",softfloat". Other values are unknown.
func goARMVariant(arch, raw string) string {
	if arch != "arm" {
		return ""
	}
	variant, _, _ := strings.Cut(raw, ",")
	if variant == "6" || variant == "7" {
		return variant
	}
	return ""
}
```

Replace `AssetFor`:

```go
// AssetFor returns the asset for an OS, architecture and 32-bit ARM variant, if
// the fallback has one. An asset naming the host's goarm wins; otherwise an
// asset without goarm matches. An asset naming a goarm never matches another
// or an unknown variant.
func (f Fallback) AssetFor(osName, arch, goarm string) (Asset, bool) {
	var generic Asset
	found := false
	for _, a := range f.Assets {
		if a.OS != osName || a.Arch != arch {
			continue
		}
		switch {
		case a.GoARM != "" && a.GoARM == goarm:
			return a, true
		case a.GoARM == "" && !found:
			generic, found = a, true
		}
	}
	return generic, found
}
```
